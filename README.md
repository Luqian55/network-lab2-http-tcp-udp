# 计算机网络实验2：HTTP客户端与TCP、UDP协议分析

本仓库用于保存实验2的 Python Socket 程序与实验代码。

## 实验内容

- Part A：UDP、TCP 基础 Socket 程序
- Part B：TCP 正常交互、异常连接、强制终止与 RTT 分析
- Part C：UDP 报文、无连接、IP 分片与 ICMP 端口不可达
- Part D：使用 Python 标准库 `socket` 实现 HTTP 客户端 `webget`

## 目录说明

- `code/`：实验中的 Python 程序及 UDP 大报文测试数据
- `captures/`：Wireshark 抓包文件，随 Word 报告通过 FTP 提交

## 运行环境

- Windows 11
- Debian 虚拟机
- VMware NAT / VMnet8
- Python 3.10 及以上
